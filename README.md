# ReadmissionIQ
AI-powered healthcare readmission intelligence application built using Snowflake Cortex, Snowpark Python, SQL, and Streamlit that analyzes CMS Hospital Readmissions Reduction Program (HRRP) data and generates executive-level insights using Snowflake Cortex.

## Overview

Hospital readmissions are an important healthcare quality metric that can impact patient outcomes, healthcare costs, and CMS reimbursement programs.

ReadmissionIQ enables users to explore readmission trends through natural language questions and receive AI-generated analytical summaries and operational recommendations.

## Features

* Natural language healthcare analytics
* CMS Hospital Readmission data analysis
* Condition-specific insights:

  * AMI
  * Heart Failure
  * COPD
  * Pneumonia
  * CABG
  * Hip/Knee Replacement
* Executive-level recommendations
* Out-of-scope query handling guardrails

## Technology Stack

* Snowflake
* Snowpark Python
* Snowflake Cortex (Claude 4 Sonnet)
* SQL
* Streamlit
